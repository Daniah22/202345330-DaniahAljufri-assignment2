# Daniah Aljufri — Interactive Personal Portfolio

## Project Description

This is an interactive personal portfolio website created for Assignment 2. The project was developed from my Assignment 1 portfolio and presents my work as an artist and Integrated Design student at King Fahd University of Petroleum and Minerals in Dammam, Saudi Arabia.

The portfolio reflects my interests in 3D modeling, animation, filmmaking, game design, crafts, and visual storytelling.

## Development from Assignment 1

This website started as my Assignment 1 portfolio. For Assignment 2, I developed and improved the original version by adding more advanced visual design, real project images, a third project, interactive project previews, video links, improved content, dark and light mode, form validation, responsive layouts, hover effects, and smoother user interaction.

The website is now more professional, interactive, and suitable for presenting my creative work as a designer and artist.

## Projects

### Still There

A 3D animation project about a sock that falls under a wardrobe and discovers a tiny world made from lost objects. The project explores 3D modeling, rigging, simulations, and visual storytelling.

### One More Patient

A psychological horror game about a medical student who experiences a mental breakdown and begins performing procedures inside an abandoned hospital. The project focuses on game design, environment, narrative, and atmosphere.

### Decorator Crab

A marine-inspired jewelry organizer based on the decorator crab. This project combines product design, 3D modeling, crafts, and hands-on making.

## Interactive Features

- Dark and light mode toggle.
- The selected theme is saved using localStorage.
- Project cards include interactive arrow buttons.
- Clicking a project arrow opens the project poster inside the same website.
- Project information changes dynamically depending on the selected project.
- Video links are displayed inside the project window when available.
- The project modal can be closed using the close button, clicking outside the window, or pressing the Escape key.
- The contact form validates the user's input.
- The form displays success and error messages.
- Hover effects and smooth transitions improve the user experience.
- The layout responds to desktop, tablet, and mobile screen sizes.
